## 5. 프로덕션 출시

**테스트 및 출시 → 프로덕션 → 새 버전 만들기**

1. 처음이면 **Play 앱 서명** 안내 → **Google에서 생성한 앱 서명 키 사용**(기본값) 그대로 계속
2. App Bundle에 `magic-release.aab` 업로드
   - https://github.com/osp-foldable/foldable-app/releases/download/magic-v1.0.0/magic-release.aab
3. 버전 이름: 자동으로 `1.0.0`이 채워져요 (그대로)
4. 출시 노트:
   ```
   <ko-KR>
   마법의 폴더폰 첫 출시!
   · 궁금한 걸 마음속으로 묻고 폴더블 폰을 펼쳐 보세요
   · 옛날 폴더폰 액정에 대답이 한 글자씩 찍혀요
   · 대답은 목소리로 읽어주고, 다시듣기도 할 수 있어요
   · 결정이 어려울 때, 친구들과 장난칠 때 써 보세요
   </ko-KR>
   ```
5. **국가/지역**: **대한민국만** 추천해요 (한국어 전용, 유럽·영국은 광고 동의 팝업 필요)
6. **검토를 위해 전송 전에 지원 기기 확인**
   - **출시 → 기기 카탈로그**에서 `Galaxy Z Fold` 검색 → **지원됨**인지 확인 (플립도 지원됨이 정상)
   - 폴드가 **지원되지 않음**이면 전송하지 말고 알려주세요
7. **다음 → 저장 → 검토를 위해 전송**. 보통 1~3일 안에 결과가 나와요.

## 6. 출시 후

- AdMob → 앱 → 마법의 폴더폰 → 앱 설정 → **앱 스토어 세부정보 추가**로 Play 앱 연결 (연결 전에는 광고 게재가 제한될 수 있어요)
- `app-ads.txt`는 펼쳐 뽑기와 같은 AdMob 계정(같은 게시자 ID)이라 `foldable.ohsangplay.com/app-ads.txt` 한 줄로 두 앱 모두 확인돼요
- 스토어에서 받아서 확인: 펼치면 수신 중 → 진동 → 대답 + 목소리, 다시듣기, 소리 켬/끔, 하단 배너. **실제 광고는 본인이 누르지 말기**
- 목소리가 안 나오면: 설정 → 일반 → 텍스트 음성 변환(TTS)에서 기본 엔진과 한국어 음성 데이터를 확인

**다음 버전 빌드**
- `git push origin main:release/magic-v1.0.1` (또는 Claude에게 "마법의 폴더폰 1.0.1로 빌드해줘")
- 대답 문구를 추가하면 액정 글꼴(한글 2,350자)에 있는 글자인지 확인해야 해요 (Claude가 빌드 전에 확인)

**자주 걸리는 부분**
- **광고 신고 불일치**: 광고 "예", 광고 ID "예", 데이터 보안의 기기 ID 항목이 서로 맞아야 해요
- **지식재산권**: 설명·스크린샷·키워드에 원작 이름이나 캐릭터를 쓰면 신고로 앱이 내려가고 계정에 경고가 쌓일 수 있어요
- **최소 기능**: 대답·목소리·다시듣기·소리 설정이 있어 괜찮을 가능성이 높아요. 거절되면 대답 기록이나 질문 입력 같은 기능을 더하면 돼요
- **버전 코드**: 같은 번호는 다시 못 올려요. 빌드를 다시 돌리면 자동으로 올라가요
