# 펼쳐 뽑기 - 랜덤 숫자 (apps/pick)

갤럭시 폴드에서 **접었다 펴면** 1~최대 숫자 중 하나가 가운데에서 튀어나오는 앱.

- 앱 이름: 펼쳐 뽑기 (스토어 제목: 펼쳐 뽑기 - 랜덤 숫자)
- 패키지: `com.ohsang.util.foldpick` (스토어에 올린 뒤엔 변경 불가)
- 출시 태그: `pick-v<버전>` / Secrets 접두사: `PICK_`
- minSdk 29 / targetSdk 36

## 파일 구성
| 파일 | 역할 |
|---|---|
| `core/fold` 의 `FoldPosture.kt` | 접힘/펼침 감지 (FoldingFeature 유무 + 짧은 변 600dp 기준) |
| `DrawViewModel.kt` | 뽑기, 중복 제외, 최대값(2~999) 보정, 설정 저장(SharedPreferences) |
| `MainActivity.kt` | 접힘 상태 수집, 화면 꺼짐 감지 |
| `ui/Screens.kt` | 시안 ①~⑤ 화면과 화면 전환 규칙 |
| `ui/Components.kt` | 입력칸, 프리셋(10·20·50·100), 토글, 튀어나오는 숫자 애니메이션 |

## 화면 전환 규칙
- **접힘(커버)**: 시작 전이면 ① 설정, 시작 후엔 ② 대기
- **펼침(메인)**: 완료 상태면 ⑤ / 설정 열림 또는 아직 안 뽑았으면 ④ / 그 외 ③ 숫자 공개
- **접힘 → 펼침**이 들어오면 숫자를 뽑음 (펼친 상태로 앱을 켠 경우엔 뽑지 않음)
- 숫자 값이나 중복 제외를 바꾸면 기록 초기화

## 폴더블이 아닌 기기
힌지 센서가 없고 접힘↔펼침 전환도 없으면 일반 폰·태블릿으로 보고, 화면에 **뽑기 버튼**을 보여줌 (Play 심사관이 일반 폰으로 테스트해도 동작하도록)

## 실제 기기에서 꼭 확인할 것
1. 메인 화면에서 접을 때 화면이 꺼지는 기본 설정이면 '접힘'이 안 들어올 수 있어서,
   **화면 꺼짐을 접힘으로 간주**하도록 처리함. 그래서 펼친 채로 전원 버튼을 껐다 켜도 새 숫자가 나옴 → 괜찮은지 확인
2. 커버 화면 ↔ 메인 화면 전환 때 앱이 다시 시작되지 않는지 (`configChanges` 설정해 둠)
3. 진동 세기, 애니메이션 속도(0.6초)
