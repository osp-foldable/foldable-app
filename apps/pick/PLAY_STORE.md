## 0. 순서

테스트 트랙 없이 **바로 프로덕션**으로 출시해요.

1. 웹사이트(개인정보처리방침) 열기 (0-1번)
2. Play Console에서 앱 만들기, 앱 설정, 스토어 등록정보 (1~4번)
3. **프로덕션** 새 버전에 `pick-release.aab`(1.0.3) 업로드 → **지원 기기에 폴드가 있는지 확인** → 검토를 위해 전송 (5번)
4. 출시 후 AdMob 앱 설정에서 **스토어에 연결** (6번)

## 0-1. 웹사이트 연결 (처음 한 번)

1. 저장소 **Settings → Pages → Build and deployment → Source: GitHub Actions**
2. **Actions → Pages → Run workflow** (또는 `site/` 아무 파일이나 고쳐서 main에 push)
   - 여기까지 하면 `https://osp-foldable.github.io/foldable-app/` 로 열려요
3. Cloudflare → ohsangplay.com → DNS → 레코드 추가
   - 유형 `CNAME`, 이름 `foldable`, 대상 `osp-foldable.github.io`, **프록시 끔(DNS 전용)**
4. 저장소 **Settings → Pages → Custom domain**에 `foldable.ohsangplay.com` 저장 → 몇 분 뒤 **Enforce HTTPS** 체크
5. 확인: https://foldable.ohsangplay.com/pick/privacy.html , https://foldable.ohsangplay.com/app-ads.txt

- `app-ads.txt`는 Pages 워크플로가 `PICK_ADMOB_APP_ID` Secret에서 게시자 ID(`pub-…`)를 꺼내 자동으로 만들어요.

## 5. 프로덕션 출시

**테스트 및 출시 → 프로덕션 → 새 버전 만들기**

1. 처음이면 **Play 앱 서명** 안내 → **Google에서 생성한 앱 서명 키 사용**(기본값) 그대로 계속
2. App Bundle에 `pick-release.aab` 업로드
   - https://github.com/osp-foldable/foldable-app/releases/download/pick-v1.0.3/pick-release.aab
   - 1.0.2 이하는 폴더블 제한이 없거나 예전 패키지명이라 **올리지 마세요**
3. 버전 이름: 자동으로 `1.0.3`이 채워져요 (그대로)
4. 출시 노트:
   ```
   <ko-KR>
   펼쳐 뽑기 첫 출시!
   · 폴더블 폰을 접었다 펴면 랜덤 숫자가 짠! 하고 튀어나와요
   · 최대 숫자는 2~999까지, 10·20·50·100은 버튼 한 번으로
   · 중복 제외를 켜면 모든 숫자가 한 번씩만 나와요
   · 모임 벌칙, 발표 순서, 자리 정하기에 써 보세요
   </ko-KR>
   ```
5. **국가/지역**: **대한민국만** 추천해요. 앱이 한국어 전용이고, 유럽(EEA)·영국에 배포하면 광고 동의 팝업(UMP)을 따로 넣어야 해요.
6. **검토를 위해 전송 전에 지원 기기 확인** (중요)
   - **출시 → 기기 카탈로그**에서 `Galaxy Z Fold` 검색 → **지원됨**인지 확인 (`Galaxy Z Flip`도 지원됨으로 나오는 게 정상)
   - 일반 폰(예: `Galaxy S24`)은 **지원되지 않음** – "기기에 필요한 기능이 없음: android.hardware.sensor.hinge_angle"으로 나오면 정상
   - 만약 폴드가 **지원되지 않음**이면 전송하지 말고 알려주세요. 제한을 빼고 다시 빌드해야 해요
   - 또는 **App Bundle 탐색기 → 버전 1.0.3 → 지원 기기 수**로도 볼 수 있어요
7. **다음 → 저장 → 검토를 위해 전송**. 보통 1~3일 안에 결과가 나와요.

- 디버그 APK를 깔아둔 폰이면 서명이 달라서 먼저 지워야 스토어 버전이 설치돼요.

## 6. 출시 후

- AdMob → 앱 → 펼쳐 뽑기 → 앱 설정 → **앱 스토어 세부정보 추가**로 Play 앱 연결 (연결 전에는 광고 게재가 제한될 수 있어요)

- 스토어에서 받아서 확인: 접은 화면에서 최대 숫자 정하기 → 시작하기 → 펼치면 숫자 + 진동, 하단 배너. **실제 광고는 본인이 누르지 말기** (AdMob 계정 정지 위험)

**다음 버전 빌드**
- `git push origin main:release/pick-v1.0.4` (또는 Claude에게 "1.0.4로 빌드해줘") → 릴리스에 AAB·APK 첨부
- 버전 코드는 Actions 실행 번호라 자동으로 커져요

**자주 걸리는 부분**
- **광고 신고 불일치**: 광고 "예", 광고 ID "예", 데이터 보안의 기기 ID 항목이 서로 맞아야 해요. 하나라도 "아니요"면 거절돼요.
- **심사관 기기**: 폴더블 전용이라 심사관이 폴더블 기기나 에뮬레이터로 확인해요. 혹시 일반 환경에서 열려도 동작하도록 앱 안에 **뽑기 버튼 대비책**을 남겨뒀어요.
- **최소 기능**: 숫자 범위·프리셋·중복 제외·기록·완료 화면이 있어 괜찮을 가능성이 높아요. 거절되면 이름 뽑기(목록 입력) 같은 모드를 더하면 돼요.
- **버전 코드**: 같은 번호는 다시 못 올려요. 빌드를 다시 돌리면 자동으로 올라가요.
