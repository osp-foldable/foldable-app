## 0. 순서

1. 웹사이트(개인정보처리방침) 열기 (0-1번)
2. Play Console에서 앱 만들기, 앱 설정 (1~3번)
3. **내부 테스트**에 `pick-release.aab` 직접 업로드 (5번), 본인 폰에 설치해서 확인
4. 문제없으면 같은 버전을 **프로덕션**으로 승격 (6번)
5. 출시 후 AdMob 앱 설정에서 **스토어에 연결**

## 0-1. 웹사이트 연결 (처음 한 번)

1. 저장소 **Settings → Pages → Build and deployment → Source: GitHub Actions**
2. **Actions → Pages → Run workflow** (또는 `site/` 아무 파일이나 고쳐서 main에 push)
   - 여기까지 하면 `https://osp-foldable.github.io/foldable-app/` 로 열려요
3. Cloudflare → ohsangplay.com → DNS → 레코드 추가
   - 유형 `CNAME`, 이름 `foldable`, 대상 `osp-foldable.github.io`, **프록시 끔(DNS 전용)**
4. 저장소 **Settings → Pages → Custom domain**에 `foldable.ohsangplay.com` 저장 → 몇 분 뒤 **Enforce HTTPS** 체크
5. 확인: https://foldable.ohsangplay.com/pick/privacy.html , https://foldable.ohsangplay.com/app-ads.txt

- `app-ads.txt`는 Pages 워크플로가 `PICK_ADMOB_APP_ID` Secret에서 게시자 ID(`pub-…`)를 꺼내 자동으로 만들어요.

## 5. 내부 테스트

**테스트 및 출시 → 테스트 → 내부 테스트**

1. **테스터** 탭 → **이메일 목록 만들기** → 이름 `펼쳐 뽑기 내부` → 본인 Gmail → 저장
2. **새 버전 만들기**
   - 처음이면 **Play 앱 서명** 안내 → **Google에서 생성한 앱 서명 키 사용**(기본값) 그대로 계속
   - App Bundle에 `pick-release.aab` 업로드 (https://github.com/osp-foldable/foldable-app/releases 의 최신 `pick-v…`)
   - 출시 노트:
     ```
     <ko-KR>
     첫 테스트 버전이에요. 최대 숫자를 정하고 폰을 펼쳐 보세요.
     </ko-KR>
     ```
3. **다음 → 저장 → 내부 테스트로 출시 시작**
4. 테스터 탭의 **링크 복사** → 휴대폰에서 열어 **테스터 되기** → Play 스토어에서 설치
   - 디버그 APK를 깔아둔 폰이면 서명이 달라서 먼저 지워야 설치돼요.

**확인할 것**
- (폴더블) 접은 화면에서 최대 숫자 정하기 → 시작하기 → 펼치면 숫자 + 진동
- (폴더블) 접었다 펴기 반복 → 중복 제외가 지켜지는지, 다 뽑으면 완료 화면
- (일반 폰) 시작하기 → **뽑기** 버튼으로 숫자가 나오는지
- 접은 화면·펼친 화면 모두 하단 배너가 화면 폭에 맞게 나오는지. 새 광고 단위는 하루 정도 광고가 안 뜰 수 있어요. **실제 광고는 본인이 누르지 말기** (AdMob 계정 정지 위험)

**출시 후**
- AdMob → 앱 → 펼쳐 뽑기 → 앱 설정 → **앱 스토어 세부정보 추가**로 Play 앱 연결 (연결 전에는 광고 게재가 제한될 수 있어요)
- AdMob → 앱 → **app-ads.txt** 탭에서 `foldable.ohsangplay.com` 확인 상태 보기 (Play 등록정보의 웹사이트 도메인 루트를 확인해요)

**다음 버전 빌드**
- `git push origin main:release/pick-v1.0.2` (또는 Claude에게 "1.0.2로 빌드해줘") → 릴리스에 AAB·APK 첨부
- 버전 코드는 Actions 실행 번호라 자동으로 커져요

**자주 걸리는 부분**
- **광고 신고 불일치**: 광고 "예", 광고 ID "예", 데이터 보안의 기기 ID 항목이 서로 맞아야 해요. 하나라도 "아니요"면 거절돼요.
- **기능 동작 안 함**: 심사관이 일반 폰으로 테스트할 수 있어서 뽑기 버튼을 넣어뒀어요. 이 부분을 빼면 "앱이 작동하지 않음"으로 거절될 수 있어요.
- **최소 기능**: 숫자 범위·프리셋·중복 제외·기록·완료 화면이 있어 괜찮을 가능성이 높아요. 거절되면 이름 뽑기(목록 입력) 같은 모드를 더하면 돼요.
- **버전 코드**: 같은 번호는 다시 못 올려요. 빌드를 다시 돌리면 자동으로 올라가요.
